EduLog – Student Management System

EduLog is a fullstack web application designed to help students and teachers manage academic activities such as schedules, grades, and course tracking in a centralized platform.

Key Features

- Student and teacher authentication system
- Role-based access control (student / teacher / admin)
- Schedule and timetable management
- Grade tracking system
- Cloud-based file storage (AWS S3)
- Secure authentication using AWS Cognito
- Responsive UI built with React

Tech Stack

- Frontend: React, Next.js
- Backend: Node.js, Express
- Database: PostgreSQL
- Cloud: AWS (S3)
- Auth: AWS Cognito

Architecture

The system follows a client-server architecture:
- Frontend communicates with REST API
- Backend handles business logic and authentication
- PostgreSQL stores relational data
- AWS services handle authentication and file storage

Project Purpose

This project was developed as a full-cycle learning experience, covering frontend, backend, database design, authentication systems, and cloud infrastructure integration.
